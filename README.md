# Городская библиотека — сайт на Bootstrap

Учебный сайт городской библиотеки: каталог книг, страница книги, бронирование и модальное окно быстрого заказа. Интерфейс собран на CSS-фреймворке Bootstrap.

## Подключение Bootstrap

Bootstrap подключён **локально**, без CDN. Файлы фреймворка (compiled-версия) размещены в папке `vendor/bootstrap/`:

- `vendor/bootstrap/css/bootstrap.min.css` — подключается в `<head>`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — подключается перед `</body>`; нужен для меню на мобильных, модального окна, вкладок, аккордеона, карусели и уведомлений.

Собственный файл `css/custom.css` подключается **после** Bootstrap, чтобы переопределять его стили:

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css">
```

## Bootstrap-сетка

- `container` — центрированный контейнер с отступами по краям на всех страницах;
- `row` + `col-12`, `col-md-*`, `col-lg-*` — hero, преимущества, каталог (фильтры `col-lg-3` + список `col-lg-9`), страница книги, форма, подвал;
- `row-cols-2 row-cols-lg-4` / `row-cols-xl-3` — сетка карточек: 2 колонки на телефоне, 3–4 на компьютере;
- `g-3`, `g-4`, `g-md-4`, `g-lg-5` — отступы между колонками.

## Реализованные компоненты

Обязательные:

- `navbar` — на всех страницах, на узком экране сворачивается в кнопку;
- `card` — карточки книг и преимуществ, блоки на страницах;
- `btn` — варианты `btn-primary`, `btn-outline-primary`, `btn-outline-secondary`, размеры `btn-sm`, `btn-lg`, неактивная `disabled`;
- `badge` — «Хит», «Новое», «Редкое издание», жанр, «В наличии» / «Выдана»;
- `alert` — объявление на главной (закрывается), счётчик в каталоге, подсказки, сообщение об отправке заявки;
- `modal` — быстрое бронирование книги;
- `form-control`, `form-select`, `form-check` — поля, списки, чекбоксы и радиокнопки;
- `input-group` — телефон с префиксом `+7`, e-mail с `@`, поиск с кнопкой.

Дополнительные:

- `accordion` — частые вопросы на главной;
- `carousel` — мероприятия на главной;
- `nav-tabs` — вкладки на странице книги;
- `toast` — всплывающее уведомление после отправки формы;
- `pagination` — страницы каталога;
- `breadcrumb` — хлебные крошки;
- `list-group` — шаги заявки, отзывы, контакты;
- `table` — характеристики книги, часы работы;
- `form-switch` — переключатель «Только в наличии».

## custom.css

В `css/custom.css` только то, чего нет в стандартных классах Bootstrap:

- коричневая палитра в CSS-переменных `:root` и подмена переменных Bootstrap (`--bs-primary`, `--bs-btn-bg` и др.) — без `!important`;
- оформление hero-блока (тёмный фон с градиентом);
- модификаторы карточек: `book-card--rare` (золотая рамка), `book-card--unavailable` (приглушённая обложка);
- состояния: подъём карточки при `:hover`, `:focus-within`, видимый `:focus-visible`;
- слайды карусели, прилипающий блок фильтров на широком экране, уточнения для мобильных.

## Самостоятельные доработки

- Bootstrap подключён локально из `vendor/bootstrap/`;
- дополнительная страница `contacts.html`;
- дополнительные компоненты: `accordion`, `carousel`, `nav-tabs`, `toast`, `pagination`, `breadcrumb`, `list-group`, `form-switch`;
- собственные SVG-обложки для всех книг;
- карточки со статусом наличия: у выданных книг неактивная кнопка и приглушённая обложка;
- сценарий заявки: кнопка «Забронировать» подставляет книгу в модальное окно, форма проверяется (`was-validated`, подсказки `invalid-feedback`), после отправки окно закрывается и показывается уведомление;
- адаптивность: на телефоне нет горизонтальной прокрутки, карточки идут в 2 колонки, фильтры прилипают только на широком экране;
- единая палитра через переменные Bootstrap.

## Как проверить

- **Меню:** сузить окно до ширины телефона и нажать кнопку меню.
- **Модальное окно:** на главной или в каталоге нажать «Забронировать» у книги — в окне появится её название.
- **Форма:** нажать «Отправить» с пустыми полями (появятся подсказки), затем заполнить: телефон в формате `(900) 123-45-67`.
- **Вкладки:** на странице книги переключить «Характеристики» и «Отзывы».
- **Аккордеон и карусель:** блоки «Частые вопросы» и «Мероприятия» на главной.
